Physics Notes

The Bohr Model — Key Principles

⚛️

Quantised Orbits

Electrons can only occupy specific orbits where the angular momentum is an integer multiple of ℏ. Between orbits, electrons do not exist.

L = nℏ, n = 1, 2, 3...
📐

Orbital Radius

Each orbit has a precise radius proportional to n². The Bohr radius a₀ ≈ 0.529 Å defines the scale of the innermost shell.

rₙ = a₀ · n²
⚡

Energy Levels

Each shell has a precise energy. Photons are emitted when electrons fall to lower shells — the energy difference determines the photon's frequency.

Eₙ = −13.6 eV / n²
🌊

Wave-like Orbits

de Broglie later showed the orbits correspond to standing waves. The orbit circumference must equal an integer number of wavelengths.

2πrₙ = nλ
